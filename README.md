# My AI Assistant

Your Personal AI Assistant.

## About

My AI Assistant is a personal AI application
built using Flutter and Dart.

## Features

- AI Chat
- ChatGPT Integration
- Google Gemini Integration
- DeepSeek Integration
- Voice Assistant
- AI Memory
- Web Search
- Agent Mode
- File Support
- Dark and Light Theme
- Hindi, English and Hinglish Support

## Technology

- Flutter
- Dart
- Provider
- Android

## Privacy

User privacy and secure API handling
are important parts of this project.
